# French Contrast V3: Exercise List (for Steven's approval)

Every contrast block runs in this order: **1 Heavy → 2 Plyo → 3 Loaded jump → 4 Fast/reactive**, done once. Rest about 20s between exercises and 2-3 min between blocks. Blocks 4-5 are optional.

Kept from V2 where they fit. New or changed items are marked ★. Dropped from V2: every reaction-ball drill, chest-supported rows, the Zercher squat, and the tennis movement section (its footwork now lives in the reactive slot).

## Rule check

- **Drop jumps:** A has 1 (FC1), B has 0 (one drop catch), C has 1 plus a drop catch. All under the cap of 2.
- **Footwork:** split-step drill in A FC2, B FC3, C FC3. All in the required blocks.
- **Lateral block in 1-3:** A FC3, B FC3, C FC2.
- **Iso:** Copenhagen (A, C), Pallof iso hold (B), split squat hold (C). One iso-pause heavy lift on A and B.
- **Loaded core:** landmine rainbow (A), heavy Pallof hold (B), sandbag lateral lunge (C).
- **Adductors/abductors daily:** slider matrix every day, plus Copenhagen (A, C) and banded abduction (B).
- **Drops progression:** every drop jump's how-to says weeks 1-2 = drop catch and stick, weeks 3+ = full rebound.
